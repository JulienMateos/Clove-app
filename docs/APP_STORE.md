## 8. Notes pour l'examen (App Review Notes)

```
Clove est une app de rencontre "IRL-first" : au lieu de swiper des profils,
l'utilisateur active un mode de disponibilité (Full) et l'app le met en relation
avec une personne compatible à proximité via un défi à réaliser en personne.

COMMENT TESTER LE PARCOURS COMPLET (deux comptes nécessaires) :
Le déclenchement d'un match demande DEUX utilisateurs compatibles proches l'un
de l'autre. Merci de tester sur deux appareils/simulateurs, ou d'utiliser les
deux comptes de démonstration ci-dessous.

1. Ouvrir l'app sur deux appareils. Créer / se connecter avec les 2 comptes démo.
2. Accepter le consentement (localisation + conditions).
3. Sur les deux, passer en mode "Full" (onglet Radar).
4. Les deux comptes démo partagent une position simulée identique : un match se
   déclenche automatiquement en quelques secondes.
5. Les deux tapent "Intéressé·e", réalisent le défi photo, puis valident.
   -> écran "C'est un Match !" + point de rencontre + chat débloqué.

SÉCURITÉ / GUIDELINE 1.2 :
- Signaler / Bloquer : menu "⋯" sur tout profil rencontré (écran de match ou chat).
- Filtre de contenu actif sur photos et messages.
- Suppression de compte : Profil -> "Supprimer mon compte" (purge immédiate).

COMPTES DE DÉMONSTRATION :
Utilisateur A — e-mail : review-a@clove.app / mot de passe : ClovoReview2026!
Utilisateur B — e-mail : review-b@clove.app / mot de passe : ClovoReview2026!
(Comptes pré-vérifiés, réglés en mode extraverti, position simulée commune.)

CLASSIFICATION : 17+ (rencontres, contenu généré par les utilisateurs).
```
